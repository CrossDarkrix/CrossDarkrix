# CrossDarkrix

中学時代にブラクラから HTML を学び、高校生の時に趣味で始めた Python を独学で学び15年。Pythonista 3 関連から Artifacter for Windows を始め、iLauncher など数々のソフトやアプリを個人で開発しています。

「自分が困ったこと」を潰す道具を作るのが専門です。作ったものは基本的に無料で公開しています。

## 主な作品

### iLauncher
iOS 風の Android ホームアプリ (Kotlin、フレームワーク標準 View のみで実装)。
- 無料版: [GitHub Releases (v0.29.2)](https://github.com/CrossDarkrix/iLauncher/releases)
- 拡張版 iLauncher-Extra (テーマ / コントロールセンター収録): [BOOTH](https://crossdarkrix.booth.pm/items/9202866)

### WinAirDrop
iPhone から Windows へ、AirDrop のように写真を送る仕組み。自宅 LAN 内の WebDAV サーバー (Go 製の単体 exe) + iOS ショートカットで動きます。家族も日常的に使用中。
- https://github.com/CrossDarkrix/WinAirDrop

### WAMB (Win Anti Malware Blocker)
ClamAV を主軸にした、Windows 向けの軽量マルウェア対策 (Go 製、単体 exe)。Defender の置き換えではなく「セカンドオピニオン」として重ねる設計です。
- https://github.com/CrossDarkrix/WAMB

### ClipboardShare
LAN 内でクリップボードを共有するツール。PC とスマホの間で、コピーしたテキストをそのまま行き来させます。
- https://github.com/CrossDarkrix/ClipboardShare

### DSRE-Audio-Enhancer
DSEE HX に着想を得た、倍音生成型の音響アップサンプリングツール。音声ファイルをハイレゾ化します。
- https://github.com/CrossDarkrix/DSRE-Audio-Enhancer

### win.APK-UCRT-Editon
Windows の Java VM で Android アプリをネイティブ実行する win.apk のフォーク。UCRT 専用に調整し、CD 読み込みと USB DAC のほぼダイレクト接続を実装。
- https://github.com/CrossDarkrix/win.APK-UCRT-Editon

### その他
- [Ultra-Lite-Desktop-Studio](https://github.com/CrossDarkrix/Ultra-Lite-Desktop-Studio) — デスクトップ常駐ガジェット LiteDesktopStudio の C++ 軽量版 (メモリ 56.7MB / CPU 0.1%)
- [Artifacter](https://github.com/CrossDarkrix/ArtifacterBuildCardImageGenerator) — 原神のビルドカード作成ツール。終了した Discord Bot を 0 から書き直して維持中
- [sshdog-android-Termux](https://github.com/CrossDarkrix/sshdog-android-Termux) — Termux で動く SSH サーバーのパッチ版
- Minecraft Bedrock アドオン (Angel Block / Logistics Node 系ほか) を CurseForge で公開中
